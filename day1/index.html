    Day 1: Linux Command Reference for Biologists

    In Linux, data is organized into files and directories (folders). While you can use a Graphical User Interface (GUI), most bioinformatics tools require the Terminal (Ctrl + Alt + T).

    Note: Use man <command> to view the manual for any tool. Press q to exit the manual.

    Notation: $ indicates the prompt (do not type it). # indicates a comment.

    1. Basic File and Folder Navigation

    Listing Files (ls)

    • # List files in a directory $ ls
    • # List files one per line $ ls -1
    • # Long format (with details and human-readable sizes) $ ls -lh
    • # Sort by time modified (newest first) $ ls -lt

    Handling Directories (cd, mkdir, pwd)

    • # Change to a specific directory $ cd my_folder
    • # Go to the home directory $ cd
    • # Go up to the parent directory $ cd ..
    • # Get the present working directory path $ pwd
    • # Create a new directory $ mkdir new_folder

    Copy, Move, and Delete (cp, mv, rm)

    • # Copy a file $ cp file1 file_copy
    • # Rename a file $ mv old_name new_name
    • # Delete a file (Warning: No Recycle Bin!) $ rm file1

    2. Viewing and Inspecting Files

    Quick Peeks (head, tail, cat)

    • # Print first 10 lines $ head sample.fastq
    • # Print last 50 lines $ tail -n 50 sample.fastq
    • # Remove headers (print starting from line 2) $ tail -n +2 data.tsv
    • # Merge two files into one $ cat file1 file2 > file3

    Word and Line Counting (wc)

    • # Count lines in a file (useful for counting sequences) $ wc -l reads.fastq

    3. File Manipulation & Data Wrangling

    Extracting Columns (cut)

    • # Get 1st and 4th columns from a tab-separated file $ cut -f 1,4 file.tsv

    Sorting Data (sort)

    • # Numerical sort on the 4th column $ sort -nr -k 4 file1
    • # Version sort (ideal for chromosomes: chr1, chr2, chr10) $ sort -V file1

    Advanced Manipulation (awk, grep)

    • # Calculate difference between columns 3 and 2 $ awk '{print $3-$2}' file.bed
    • # Search for a specific gene or chromosome $ grep -w 'chr1' peaks.tsv

    4. Meta Characters & Pipes

    • Wildcards (*): Match any characters. $ ls *.fastq (Lists all fastq files).
    • Redirection (>): Save output to a file. $ ls *.txt > file_list.
    • The Pipe (|): Use the output of one command as the input for the next. $ ls *.fastq | wc -l (Count how many fastq files exist).

    5. Compressed Files (Bioinformatics Standard)

    • # Compress a file $ gzip reads.fastq
    • # View a compressed file without unzipping $ zcat reads.fastq.gz | head
