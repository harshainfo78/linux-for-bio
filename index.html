    Day 1: Linux Fundamentals for Biologists

    Welcome to your first day of the IBDC-HPC Workshop. Today, we bridge the gap between biological data and computational power.

    1. Why Linux for Biology? (30 mins)

    Traditional operating systems often fail when handling large-scale genomic data.

    • Massive File Handling: Linux can read a 50GB FASTQ file in milliseconds, whereas Excel or Notepad would crash.
    • Stability: Linux systems are built to run for months, perfect for long-running bioinformatics pipelines.
    • Reproducibility: Every command you type can be saved in a script, ensuring your experiment can be repeated exactly by others.

    2. Navigating the "Digital Lab" (The Map)

    Think of the Linux directory tree as your lab's storage room. Everything starts from the Root (/).

    Essential Navigation Commands

    Command Biology Context What it does
    pwd "Which shelf am I at?" Print Working Directory (shows your current path).
    ls -lh "Check the inventory." List files with human-readable sizes (MB/GB).
    cd "Walk to a new room." Change Directory (e.g., cd raw_data/).
    mkdir "Set up a new bench." Make Directory (e.g., mkdir mouse_project).

    3. Managing Data Without a Mouse (The Action)

    In bioinformatics, we rarely click "Save As." Instead, we use commands to manipulate files.

    Viewing Data

    • Peek at DNA reads: Don't open the whole file; just look at the top.
      • head -n 4 sample.fastq (Shows the first sequence read).
    • Check the end of a log:
      • tail -n 10 analysis.log (See if your process finished).

    File Operations

    • Back up raw data: Always keep a copy before you start filtering.
      • cp raw_seq.fastq raw_seq_backup.fastq.
    • Organizing files:
      • mv results.txt ./final_output/ (Moves the file to the results folder).
    • Deleting (Warning!):
      • rm temp_file.txt (There is no recycle bin in Linux. It is gone forever!).

    4. Practical Hands-on Exercise (60 mins)

    Follow these steps in your terminal to create your first workspace.

    1. Create your folder: mkdir workshop_practice
    2. Enter the folder: cd workshop_practice
    3. Create a dummy sequence: echo "ATGCATGCATGC" > dna_sequence.txt
    4. Confirm the file exists: ls -l
    5. Check your current location: pwd (Ensure you see /home/harsha/workshop_practice).

    5. Pro-Tips for Speed

    • Tab Completion: Type the first 3 letters of a folder name and hit Tab. Linux will finish the word for you!.
    • Command History: Use the Up Arrow key to find commands you typed earlier.
    • Naming Rule: Never use spaces in filenames (e.g., use mouse_data.txt, not mouse data.txt).
