    Linux & HPC: A Quick Guided Tour

    1. Introduction

    With the constant evolution of scientific knowledge, biologists face an increasing need for bioinformatics skills to deal with high-throughput data storage, retrieval, and analysis. While graphical interfaces exist, many operations are more efficiently handled with the Linux Shell, which acts as both a command-line interface and a scripting language.

    A Brief History of Linux

    Linux evolved from a kernel created by Linus Torvalds in 1991. It is a family of free and open-source operating systems known for flexibility, stability, and strong security. Complete systems, known as distributions or distros, combine the kernel with software packages (e.g., Ubuntu, Fedora, CentOS).

    2. Architecture of Linux

    Linux has a layered structure that defines how its components interact to manage resources efficiently.

    1. Kernel: The core that manages hardware resources and controls communication.
    2. System Libraries: Pre-written code that allows applications to interact with the kernel.
    3. Shell: The CLI that interprets user commands and serves as a bridge to the kernel.
    4. Hardware Layer: Physical components like RAM, HDD, and CPU.
    5. System Utility: Tools provided by the OS to manage software and system performance.

    3. The Terminal, Shell, and CLI

    While often used interchangeably, there are subtle differences: * Terminal: An input/output environment presenting a text-only window. * Shell: A program that interprets your commands (e.g., Bash). * CLI: The user interface that processes commands and outputs results.

    To execute a command, type it into the prompt and press ENTER.

    4. Linux File Hierarchy Structure (FHS)

    The FHS defines the directory structure for nearly all Linux distributions. Everything starts from the Root directory (/).

    Directory Description
    /bin Important binary applications (standard commands).
    /home Where your personal data lives.
    /root Home directory for the administrator (root user).
    /etc System configuration files and startup scripts.
    /tmp Temporary files (often cleared on reboot).
    /var Variable files like logs and databases.

    5. Navigating the Filesystem

    Directories are like places. At any time, you are in exactly one place called your Current Working Directory.

    • pwd: Print Working Directory (Shows your current "address").
    • ls: Listing (See what files are in your folder).
    • cd: Change Directory (Move to a different folder).
      • cd .. moves you up one level.
      • cd ~ takes you to your Home directory.
    • Wildcards (*): Match zero or more characters (e.g., ls *.fastq).

    6. Linux Command Reference

    File Commands

    Command Action
    ls -al Formatted listing including hidden files.
    mkdir <dir> Create a new directory.
    head / tail Output the first or last 10 lines of a file.
    cp / mv Copy or move/rename a file.
    rm -rf Forcefully remove a directory and its contents.

    System & Search

    Command Action
    grep <pat> Search for a pattern in a file.
    top Display all running processes.
    chmod Change file permissions.
    df -h Show disk usage in human-readable format.

    Shortcuts

    • Ctrl + C: Halts the current command.
    • Ctrl + R: Search your command history.
    • Tab: Autocomplete file or directory names.
    • !!: Repeat the last command.
