    Linux commands

    Like most operating systems, data in Linux systems is organized into files, which are further organized into directories (folders). Both files and folders can be navigated from the Graphical User Interface as you would on a Windows or a Mac system. However, most of the commands used for data analysis are required to be run from the Terminal (opened by pressing Ctrl + Alt + T), and thus, it is convenient to be able to handle files and folders from the Terminal as well. The following sections will give an overview about various commands that are regularly used when working with Linux systems.

    Note: you can view the manual (help) page of the commands by typing man followed by the command name. Press q to exit the manual page when done. For example, man ls would open the manual page for ls, the command to list files.

    Note: $ indicates the command prompt seen in the Terminal. It is not part of the command, instead it is an indication that the command that follows is to be entered on a Terminal. # indicates a comment to explain the command that follows

    Basic File and Folder Navigation

    Listing Files

    list files in a directory

    $ ls

    list files one per line

    $ ls -1

    list in the long format (with details)

    $ ls –l

    list hidden files as well

    $ ls –a

    recursively list directory contents (including any subdirectories)

    $ ls –R

    sort by time modified (newest first)

    $ ls –t

    Options can be combined

    list in long format, with sizes in human readable format

    $ ls –lh

    list in long, human readable format, sorted by time modified in reverse order (oldest first)

    $ ls -lhtr

    Handling Directories

    use cd followed by directory to change directories

    $ cd

    go to my_folder in the current directory

    $ cd my_folder

    typing cd without any directory goes to home directory

    $ cd # goes to home directory

    use . (dot) and ..(dot dot) to refer to current and parent directories respectively

    go to parent directory

    $ cd ..

    go two levels above

    $ cd ../..

    go to last working directory

    $ cd –

    get the present working directory path

    $ pwd

    create a new directory with desired name using mkdir (make directory)

    $ mkdir new_folder

    copy a file using cp

    $ cp file1 file_copy

    specify path to generate copies in a different folder

    $ cp file1 my_folder/file1 # generates a copy of file1 in my_folder

    move or rename a file using mv

    $ mv file1 my_folder/file1 # move file1 from current folder to my_folder $ mv file1 file2 # rename file1 as file2

    delete file(s) using rm

    $ rm my_folder/file1 # delete file1 from my_folder $ rm file1 file2 # delete file1 and file2 from current directory

    View Files and File Information

    count number of words in a file

    $ wc file1 # prints lines, words, and characters in file1

    specify –l option to output only number of lines

    $ wc –l file1 # prints number of lines in file1

    print first 10 lines of a file

    $ head file1

    print first n lines of a file

    $ head –n 100 file1 # prints first 100 lines of file1

    print last 10 lines of a file

    $ tail file1

    print last n lines of a file

    $ tail –n 50 file1 # prints last 50 lines of file1

    print starting from nth line

    $ tail –n +2 file1 # print from second line of file1 (useful for removing headers)

    print the entire file to screen using cat (stands for concatenate)

    $ cat file1

    as the name suggests, cat can be used to merge multiple files

    $ cat file1 file2 # prints both file1 and file2 in succession $ cat file1 file2 > file3 # merges file1 and file2 into file3

    print file page by page

    $ more file1 # use spacebar to go to next page, Enter to go to next line, q to quit

    File manipulation

    get required columns from file using cut

    $ cut –f 1,4 file.tsv # get 1st and 4th columns from a tab-separated file $ cut –f 1-3 file.tsv # get 1st to 3rd columns from file.tsv using range (-) $ cut –d ‘ ‘ –f 2 file1 # set delimiter to space instead of tab, and get second column

    join columns using paste command

    $ paste file1 file2 > file3 # merge file1 and file2 row-wise and store in file3

    sort files by column

    $ sort file1 # sort file1 by first column (default is dictionary order) $ sort –n file1 # perform numerical sort on first column of file1 $ sort –nr file1 # same as above, but in descending order $ sort –nr –k 4 file1 # sort by 4th column (using space as delimiter) $ sort –V file1 # perform version sort (useful to sort chromosomes)

    sort on the 14th column in descending order (numerical). Separator to be considered is tab

    $ sort -t $'\t' -nr -k 14 mastersheet.txt

    use awk to read a file line by line and perform some manipulation on each line

    The following command subtracts the value in column 2 from column 3 of a bed file and prints it out

    $ awk '{print $3-$2}' file.bed

    Use $0 to refer to the whole line, and $ followed by a number to access that column. The default delimiter is space, which can be changed using –F option

    $ awk –F “\t” ‘{print $0”\t”$3-$2}’ file1.tsv > file2.tsv

    The above command takes a tab-separated file (file1.tsv), calculates the difference between its 2nd and 3rd columns, and prints it as an extra column at the end of each line in file2.tsv

    find lines matching a pattern or text using grep

    $ grep ‘chr1’ peaks.tsv # get all lines with the text chr1 in peaks.tsv

    use –w option to search by exact words

    $ grep –w ‘chr1’ peaks.tsv # get only chr1 lines and not chr10, chr11 and so on

    Meta Characters The following are a few characters that have special meaning in the Terminal

    use * to match one or more optional characters

    $ ls .fastq # list all files with the extension .fastq $ wc –l .peaks # count the number of lines in all files with the extension .peaks

    use > to redirect output to another file

    $ cat file1 file2 > file3 # merge file1 and file2 into file3 $ ls *.fastq > fastq_list # list files with extension .fastq and store in a file called fastq_list

    use >> to append to a file rather than overwriting

    $ ls .txt > file_list # list all .txt files to file_list $ ls .tsv >> file_list # add all .tsv files to file_list instead of deleting the previous file

    use | (called a pipe) to join multiple commands. The output of the previous command becomes the input of the next command

    $ ls *.fastq | wc –l # list all .fastq files and count their number $ cut –f 3 file.tsv | sort > sorted.txt # extract 3rd column from file.tsv, sort the column and store in sorted.txt

    Miscellaneous

    clear the screen

    $ clear

    create a new empty file

    $ touch file1

    rewrite output back into original file using sponge

    note - this will change the original file and it cannot be regained

    $ cut –f 1-3 file.tsv | sponge file.tsv # retain only the first three columns of file.tsv

    unzip a .zip file

    $ unzip archive.zip

    zip a file using gzip compression (adds a .gz extension)

    $ gzip reads.fastq

    unzip a .gz file

    $ gunzip reads.fastq.gz

    print a .gz file (like cat, but for .gz files)

    $ zcat reads.fastq.gz $ zcat reads.fastq.gz | more # print a .gz file page by page
