    Linux & HPC Workshop: Day 1 Foundation

    Welcome to the Linux & HPC Intensive. [cite_start]This single-page guide covers the architecture, filesystem, and navigation essentials required for modern bioinformatics[cite: 213, 236].

    1. Workshop Purpose & Context

    Why Biologists Need the Command Line

    [cite_start]As high-throughput technologies evolve, biologists face an increasing need for bioinformatics skills to manage massive datasets[cite: 236]. * [cite_start]Efficiency: The Shell allows tasks to be done automatically and quickly[cite: 238]. * [cite_start]Reproduction: Proper commands allow you to repeat tasks exactly as many times as needed[cite: 239]. * [cite_start]Scale: Essential for interacting with High-Performance Computing (HPC) systems[cite: 333].

    Reducing Anxiety

    • [cite_start]Mistakes are normal: Making errors is part of the process[cite: 403].
    • [cite_start]Safety: You cannot damage the hardware through normal commands[cite: 272].
    • [cite_start]Documentation: You are not expected to memorize everything; use this guide as a reference[cite: 330, 424].

    2. Part 1: The Linux Architecture

    [cite_start]Linux is a layered system where components interact to manage resources and execute programs[cite: 259, 260].

    1. [cite_start]Hardware Layer: The physical components (CPU, RAM, HDD)[cite: 270, 271].
    2. [cite_start]The Kernel: The "brain" that manages hardware and prevents program conflicts[cite: 246, 261, 262].
    3. [cite_start]The Shell: An interpreter that acts as a bridge, forwarding your requests to the kernel[cite: 267, 268].
    4. [cite_start]The Terminal: The interactive text window where you type commands and see results[cite: 279, 284].

    Anatomy of a Command

    [cite_start]Every command follows a specific grammar: Command + Options + Arguments[cite: 312, 334].

    [cite_start]ls -l --sort time Documents/ [cite: 314]

    • [cite_start]Command (ls): The action you want to perform[cite: 315].
    • [cite_start]Option/Flag (-l): Modifies behavior, such as switching to "long" format[cite: 316, 317].
    • [cite_start]Argument (Documents/): The object the command operates on[cite: 322, 323].

    3. Part 2: The Filesystem Hierarchy

    [cite_start]Linux organizes data in a hierarchical "Inverted Tree" called the Filesystem Hierarchy Standard (FHS)[cite: 289, 346].

    • / (Root): The top-most directory. [cite_start]Everything starts here[cite: 292, 349, 350].
    • [cite_start]/home: Contains the personal directories for regular users[cite: 295, 348].
    • [cite_start]/bin: Important binary applications and commands[cite: 300].
    • [cite_start]/tmp: Temporary files that may be cleared upon reboot[cite: 300].

    4. Part 3: Navigation & Operations

    Directories are like places. [cite_start]At any time, you are in exactly one place called your "Current Working Directory"[cite: 353].

    Essential Navigation

    • [cite_start]pwd: Print Working Directory (Where am I?)[cite: 352, 355].
    • [cite_start]cd: Change Directory[cite: 370, 414].
      • [cite_start]cd ~: Teleport to your Home directory[cite: 378, 379].
      • [cite_start]cd ..: Move up one level in the tree[cite: 382].
      • [cite_start]cd -: Return to the previous folder[cite: 425].
    • [cite_start]ls -lhtr: List files in long format, human-readable, sorted by time (oldest first)[cite: 312, 425].

    File Manipulation

    • [cite_start]mkdir <name>: Create a new folder[cite: 415, 425].
    • [cite_start]cp -r <src> <dest>: Copy a file or directory recursively[cite: 417, 425].
    • [cite_start]mv <src> <dest>: Move or rename a file[cite: 416, 425].
    • rm -rf <name>: Danger Zone. Forcefully and permanently remove data. [cite_start]There is no recycle bin[cite: 418, 419, 425].
