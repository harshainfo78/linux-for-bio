    Linux & HPC: A Quick Guided Tour

    1. Introduction & Purpose

    Biologists face an increasing need for bioinformatics skills to deal with high-throughput data storage, retrieval, and analysis. While graphical interfaces exist, many operations are more efficiently handled with the Linux Shell, which acts as both a command-line interface and a scripting language.

    A Brief History

    Linux evolved from a kernel created by Linus Torvalds in 1991. It is a family of free and open-source operating systems known for flexibility, stability, and strong security.

    2. Architecture of Linux

    Linux has a layered structure that defines how its components interact to manage resources efficiently.

    • Kernel: The core that manages hardware resources and controls communication.
    • System Libraries: Pre-written code that allows applications to interact with the kernel.
    • Shell: The CLI that interprets user commands and serves as a bridge to the kernel.
    • Hardware Layer: Physical components like RAM, HDD, and CPU.
    • System Utility: Tools provided by the OS to manage software and system performance.

    3. Linux File Hierarchy Structure (FHS)

    Everything in Linux starts from the Root directory (/). The FHS defines the directory structure for nearly all Linux distributions.

    Directory Description
    /bin Important binary applications.
    /boot Boot configuration files, kernels, and files needed at boot time.
    /dev System device files.
    /etc Configuration files, startup scripts, etc..
    /home List of home directories for different users.
    /lib System libraries and shared libraries.
    /lost+found A system for files that exist under the root (/) directory.
    /media Automatically mounted partitions (CDs, digital cameras, etc.).
    /mnt Manually mounted filesystems on your hard drive.
    /opt 3rd party applications to be installed.
    /proc Information about the system state and running processes.
    /root Root user's home directory.
    /sbin Important system binaries.
    /srv Files that are served to other systems.
    /sys System files.
    /tmp Temporary files.
    /usr Applications and files available for all users to access.
    /var Variable files such as logs and databases.

    4. Navigating the Filesystem

    Directories are like places. At any time, you are in exactly one place called your Current Working Directory.

    • pwd: Print Working Directory (Shows your current "address").
    • ls: Listing (See what files are in your folder).
    • cd: Change Directory (Move to a different folder).
      • cd .. moves you up one level.
      • cd ~ takes you to your Home directory.

    5. Linux Command Reference

    Essential File Commands

    Command Action
    ls -al Formatted listing including hidden files.
    mkdir <dir> Create a new directory.
    head / tail Output the first or last 10 lines of a file.
    cp / mv Copy or move/rename a file.
    rm -rf Forcefully remove a directory and its contents.

    Shortcuts & Help

    • Ctrl + C: Halts the current command.
    • Ctrl + R: Search your command history.
    • Tab: Autocomplete file or directory names.
    • man <command>: Show the manual for a command (Type q to quit).
