    Introduction

    [cite_start]With avant-garde technologies and the constant evolution of scientific knowledge, biologists face an increasing need for bioinformatics skills to deal with high-throughput data storage, retrieval, and analysis[cite: 213, 236]. [cite_start]Although several resources have graphical user interfaces (GUIs), many operations are more efficiently handled with command-line programs and utilities[cite: 237].

    [cite_start]The Linux Shell is both a command-line interface (CLI) and a scripting language, allowing tasks to be done automatically and quickly[cite: 238]. [cite_start]With proper commands, the shell can repeat tasks as many times as wanted[cite: 239].

    A Brief History of Linux

    [cite_start]Linux evolved from a kernel created by Linus Torvalds in 1991 while he was a student at the University of Helsinki[cite: 240, 241]. [cite_start]Torvalds was using a version of UNIX called 'Minix' and decided to create his own operating system to incorporate improvements that Minix's creator did not feel were necessary[cite: 241, 242, 243].

    [cite_start]Linux is a family of free and open-source operating systems based on the Linux kernel, which acts as the "brain" of the system, managing hardware and resources[cite: 244, 245, 246]. [cite_start]Complete systems, known as distributions or distros, combine the kernel with software packages (e.g., Ubuntu, Fedora, CentOS, RHEL)[cite: 248, 250, 251].

    Importance of Linux

    [cite_start]Linux is known for its flexibility, stability, and strong security[cite: 253]. * [cite_start]Security and Stability: Ideal for servers and development[cite: 255]. * [cite_start]Open Source: Free to use, modify, and distribute[cite: 256]. * [cite_start]Customizable: Highly flexible to suit different industries[cite: 257]. * [cite_start]Ecosystem: Supported by a large global community[cite: 258].

    Architecture of Linux

    [cite_start]Linux has a layered structure that defines how its components interact[cite: 259, 260].

    1. [cite_start]Kernel: The core that manages hardware resources and controls software-hardware communication[cite: 261].
    2. [cite_start]System Libraries: Essential functions that allow applications to interact with the kernel without direct access[cite: 263, 266].
    3. [cite_start]Shell: The CLI that interprets user commands and serves as a bridge between the user and the kernel[cite: 267, 268].
    4. [cite_start]Hardware Layer: Physical components like RAM, HDD, CPU, and I/O devices[cite: 270, 271].
    5. [cite_start]System Utility: Tools provided by the OS to manage software, network settings, and system performance[cite: 274, 275].

    The Terminal, Shell, and CLI

    [cite_start]While often used interchangeably, there are subtle differences[cite: 278]: * [cite_start]Terminal: An I/O environment presenting a text-only window[cite: 279]. * [cite_start]Shell: A program (command line interpreter) that exposes the OS to the user[cite: 280, 281]. * [cite_start]Command Line Interface (CLI): The user interface that processes commands and outputs results[cite: 282].

    [cite_start]To execute a command, type it into the prompt and press ENTER[cite: 285]. [cite_start]Entering commands is often more efficient than using a graphical desktop environment[cite: 287].

    Linux File Hierarchy Structure (FHS)

    [cite_start]The FHS defines the directory structure and contents for nearly all Linux distributions[cite: 288, 289, 290]. * [cite_start]/ (Root): The top-level directory; all other files and directories appear under it[cite: 292]. * [cite_start]/home/: Contains the home directories for regular users[cite: 293, 295]. * [cite_start]/root/: The home directory for the root user (different from /)[cite: 296, 297].

    [cite_start]Common Directories [cite: 300]

    Directory Description
    /bin Important binary applications
    /boot Files needed at boot time (kernels, etc.)
    /etc Configuration files and startup scripts
    /lib System and shared libraries
    /mnt Manually mounted filesystems
    /opt 3rd party applications
    /tmp Temporary files
    /usr Applications available for all users
    /var Variable files like logs and databases

    1. The Linux Shell

    [cite_start]When opened, the shell presents a prompt, indicating it is waiting for input[cite: 301, 302]. [cite_start]Typical prompt: username@hostname:~$ [cite: 303, 304] * [cite_start]~ represents the home directory[cite: 307]. * [cite_start]$ indicates the shell is ready for commands[cite: 308].

    Command Anatomy

    [cite_start]Example: ls -l --sort time Documents/ [cite: 314] 1. [cite_start]Command (ls): The program to run (short for "listing")[cite: 310, 315]. 2. [cite_start]Options/Flags (-l, --sort): Arguments that "switch on" or change specific behaviors (e.g., long format, sorting by time)[cite: 316, 317, 321]. 3. [cite_start]Positional Argument (Documents/): Tells the command what to operate on[cite: 322, 323].

    Getting Help: Use ls --help or man ls to read the manual. [cite_start]Type q to quit the manual[cite: 328, 329, 330, 331].

    2. Navigating the Filesystem

    [cite_start]The filesystem organizes data into a hierarchical tree[cite: 336, 344, 346].

    • [cite_start]pwd (Print Working Directory): Shows your current location (e.g., /home/ibdc)[cite: 352, 355].
    • [cite_start]Path: An address specifying a file or folder's location[cite: 363].
      • [cite_start]Absolute path: Starts from root (/)[cite: 375].
      • [cite_start]Relative path: Directions from your current directory[cite: 377].
    • [cite_start]ls: Lists contents of the current directory[cite: 369].
    • cd (Change Directory):
      • [cite_start]cd /path/to/dir moves you to that location[cite: 370].
      • [cite_start]cd .. moves you up one directory[cite: 382].
    • Wildcards: * matches zero or more characters; [cite_start]? matches exactly one character[cite: 383, 384, 386].
    • [cite_start]find: Searches for files by pattern (e.g., find . -type f -name "*.txt")[cite: 387, 388, 389]. [cite_start]Use -delete with extreme caution[cite: 400, 403].

    [cite_start]Linux Command Reference [cite: 425]

    File Commands

    # Command Action
    1 ls Directory listing
    2 ls -al Formatted listing with hidden files
    5 cd <dir> Change directory to dir
    7 pwd Show current working directory
    8 mkdir <dir> Create a directory
    12 head Output first 10 lines of file
    13 tail Output last 10 lines of file
    16 rm Delete a file
    17 rm -r Delete a directory
    20 cp Copy file
    22 mv Rename or move file

    Process Management

    • ps: Display working processes.
    • top: Display all running processes.
    • kill <pid>: Kill process with given PID.

    System Info & Searching

    • grep <pattern> <file>: Search for pattern in file.
    • chmod: Change file permissions (Read=4, Write=2, Execute=1).
    • df -h: Show disk usage.
    • du -sh: Show directory space usage.
    • which <tool>: Show which application runs by default.

    Compression & Network

    • tar czf file.tar.gz files: Create Gzip compressed tar.
    • gzip file: Compress file to .gz.
    • ping host: Check connectivity.
    • wget <url>: Download file.

    Shortcuts

    • Ctrl + C: Halts current command.
    • Ctrl + R: Bring up recent command.
    • !!: Repeat last command.
    • Tab: Autocomplete file/directory names.
