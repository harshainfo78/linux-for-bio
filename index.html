    # Linux & HPC: The Foundation (Day 1)

**Welcome to the 3-Hour Intensive Workshop for Biologists.**

!!! quote "Why use the Command Line?"
    "With the avant-garde technologies and constant evolution of scientific knowledge, biologists are faced with an increasing need for bioinformatics skills to deal with high-throughput data storage, retrieval, and analysis." 

    While GUIs exist, the command line is **faster**, **scalable**, and required for **cloud servers**.

## Part 1: The Architecture (Presentation)

### The "Onion" Structure
Linux is not just one program; it is a layered architecture.

```mermaid
graph TD
    User((User / Applications)) --> Shell[The Shell: CLI]
    Shell --> Kernel[The Kernel: The Brain]
    Kernel --> HW[Hardware: CPU, RAM, Disk]

    style Kernel fill:#f96,stroke:#333,stroke-width:2px
    style Shell fill:#61dafb,stroke:#333,stroke-width:2px
    1. The Kernel: The core of the OS. It manages hardware (RAM, CPU) and prevents conflicts between programs.
    2. The Shell: A program that exposes the OS to the user. It interprets your commands and forwards them to the kernel.
    3. The Terminal: The text-only window you are looking at right now.

    Anatomy of a Command

    Commands follow a specific syntax. Let's dissect the command ls -l --sort time:

    graph LR
    A[ls] -- "Command" --> Action(List Files)
    B[-l] -- "Option/Flag" --> Format(Long Format)
    C[--sort time] -- "Option with Value" --> Sort(Sort by Time)
    D[Documents/] -- "Argument" --> Target(Target Folder)

    style A fill:#f9f,stroke:#333
    style B fill:#ff9,stroke:#333
    style C fill:#ff9,stroke:#333
    style D fill:#9f9,stroke:#333
    • Command: The program you want to run.
    • Options (Flags): Switches starting with - or -- that change behavior.
    • Argument: The target (file or directory) the command operates on.

    Part 2: The Filesystem Tree (Visual Guide)

    In Linux, everything starts from the Root (/). It is an inverted tree structure.

    The Hierarchy Map

    This structure is defined by the Filesystem Hierarchy Standard (FHS).

    graph TD
    Root["/ (Root)"] --> Bin["/bin <br>(Binaries/Apps)"]
    Root --> Home["/home <br>(User Folders)"]
    Root --> Var["/var <br>(Logs/Data)"]
    Root --> Tmp["/tmp <br>(Temporary)"]

    Home --> User1["/home/ibdc"]
    Home --> User2["/home/rcb"]

    style Root fill:#ef5350,stroke:#333,stroke-width:2px
    style Home fill:#42a5f5,stroke:#333,stroke-width:2px

    Key Directories

    Directory Description
    / The Root Directory (Start of the filesystem).
    /home Contains directories for users (e.g., /home/ibdc).
    /bin Essential command binaries (apps).
    /var Variable files like logs and databases.
    /tmp Temporary files (often deleted on reboot).

    Part 3: Navigation & Operations (Practical)

    1. Where am I?

    You are always in a "Current Working Directory."

    $ pwd
/home/ibdc
    • pwd stands for Print Working Directory.
    • ~ represents your Home Directory.

    2. Moving Around

    Use cd (Change Directory). You can use two types of paths: * Absolute Path: Starts with /. (e.g., cd /home/ibdc/data) * Relative Path: Starts from where you are. (e.g., cd data)

    !!! tip "Navigation Shortcuts" * cd ~ : Go Home. * cd .. : Go Up one level (Parent directory). * cd - : Go back to the previous directory.

    3. File Manipulation (CRUD)

    Essential commands for managing data.

    • List: ls -l (Long format), ls -lt (Sort by time).
    • Create: mkdir new_folder.
    • Copy: cp file1 copy1 or cp -r folder1/ folder_copy/.
    • Move/Rename: mv old.txt new.txt.

    !!! danger "Warning: Deletion is Permanent" * rm file.txt: Deletes a file. * rm -r folder/: Deletes a folder and contents recursively. * There is no recycle bin in the command line.

    Part 4: Day 1 Reference (Future Guide)

    Save this section for your future work.

    Navigation & Files

    Command Action
    pwd Show current directory path
    ls -ltr List files sorted by time (reverse)
    cd .. Go up one directory
    cp -r Copy directory recursively
    mv Move or Rename
    rm -rf Force remove directory (Careful!)

    Viewing Content

    Command Action
    cat Display full file content
    less Scroll through file one screen at a time
    head -n 10 Show first 10 lines
    tail -f Follow file growth (live logs)

    Search & Wildcards

    Command Action
    * Wildcard: Matches zero or more characters (e.g., *.txt).
    find . -name "*.txt" Find all text files in current folder.
    grep "pattern" file Search for text inside a file.

    System Stats

    Command Action
    top Display running processes (CPU/RAM).
    du -sh Show directory size (Human readable).
    df -h Show total disk usage.
    ```
