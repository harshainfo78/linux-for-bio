    Workshop Foundation: Linux & HPC for Biologists

    Purpose of This Workshop

    This workshop is designed to help biologists become confident users of Linux and High-Performance Computing (HPC) environments commonly used in modern biological research.

    The goal is not to turn participants into system administrators or software developers, but to provide the practical understanding and confidence needed to work effectively on Linux systems and HPC platforms.

    What You Will Gain from This Workshop

    By the end of this workshop, participants should be able to:

    • Understand what Linux and HPC systems are
    • Navigate files and directories on Linux systems
    • Follow and adapt command-line instructions
    • Run bioinformatics tools on servers or HPC
    • Submit, monitor, and manage jobs on IBDC-HPC
    • Use documentation to continue learning independently

    What This Workshop Is NOT

    To reduce unnecessary stress, it is important to clarify that this workshop does not aim to teach:

    • Linux kernel development
    • Advanced system administration
    • Networking internals
    • Software engineering or programming concepts

    These topics are outside the scope of this workshop.

    Why Biologists Need Linux and HPC

    Modern biological research generates large and complex datasets, including:

    • Next-generation sequencing data
    • Mass spectrometry data
    • Imaging data
    • Multi-omics datasets

    These datasets are often: - Too large for personal computers - Computationally intensive - Required to be processed in reproducible ways

    Linux and HPC systems enable: - Efficient large-scale computation - Automation of analysis workflows - Reproducible and scalable research

    How Learning Will Happen in This Workshop

    This workshop follows a three-step learning approach:

    1. Conceptual Understanding

    Participants first learn: - What the system does - Why certain tools and commands exist - How data and jobs move through the system

    2. Guided Practical Sessions

    Participants then: - Follow step-by-step demonstrations - Type commands along with the instructor - Learn through small, controlled examples

    3. Independent Revision and Practice

    After the workshop, participants can: - Revisit this documentation - Practice at their own pace - Apply concepts to their own research data

    A Simple Mental Model for Linux

    Linux is not mysterious or complex when viewed correctly.

    Think of Linux as a structured system that allows you to: - Store files - Organize data - Run programs - Automate repeated tasks

    Key ideas: - Everything is organized into directories - Every file has a location - Commands are simple instructions to the system

    A Simple Mental Model for HPC

    HPC systems can be understood using a simple analogy.

    HPC is like a shared research facility: - Many users share powerful resources - You request resources instead of using them directly - Jobs wait in a queue - Results are produced later

    Important concepts: - Login nodes are used for preparation - Compute nodes are used for execution - Job schedulers manage fairness and efficiency

    Reducing Fear and Anxiety

    Participants should know that:

    • Making mistakes is a normal part of learning
    • Error messages provide useful information
    • Users cannot damage the system through normal commands
    • Asking questions is encouraged and welcomed

    Learning Linux is a process, not a test.

    How to Use This Documentation

    This documentation is intended to be:

    • A conceptual guide during the workshop
    • A reference for revision after the workshop
    • A support resource for future practice

    Participants are not expected to memorize commands. Understanding concepts and workflows is the main objective.

    Workshop Ground Rules

    • Type commands yourself during practice
    • Follow instructions step by step
    • Do not rush through exercises
    • Ask questions immediately if something is unclear
    • Support and help fellow participants

    What Success Looks Like

    A participant has successfully completed the workshop if they can:

    • Log into a Linux or HPC system
    • Locate their data
    • Understand command-line instructions
    • Submit a computational job
    • Check job status and outputs
    • Know where to look for help

    Final Note

    Linux and HPC are tools that empower biological research.

    With the right foundation and guided practice, any biologist can learn to use them effectively.
