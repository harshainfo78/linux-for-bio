    Linux Foundations for Biologists: Lab Bench to CLI

    [cite_start]This guide covers the core mechanics of the Linux operating system used in high-throughput biology[cite: 2].

    1. Under the Hood: Linux Architecture

    The Shell is your bridge. [cite_start]It negotiates with the Kernel to execute commands on the Hardware[cite: 55].

    • [cite_start]Hardware: CPU, RAM, and Storage (HDD/SSD)[cite: 54].
    • [cite_start]Kernel: The "Brain" and Resource Manager[cite: 52].
    • [cite_start]The Shell: The Interpreter and Translator[cite: 49].
    • [cite_start]User & Utilities: This is where you work![cite: 47].

    2. Decoding the Interface

    [cite_start]When you look at the terminal, the Prompt tells you exactly where you are and who you are[cite: 57].

    • [cite_start]ibdc: Current User[cite: 63].
    • [cite_start]cluster: Hostname (Server Name)[cite: 65].
    • [cite_start]~: Current Location (Home Directory)[cite: 68].
    • [cite_start]$: The prompt, ready for your input[cite: 69].

    3. The Anatomy of a Command

    Commands follow a strict grammar. [cite_start]A mistake in a space or a dash will cause the command to fail[cite: 71, 79].

    ls -l --sort time Documents/

    • [cite_start]Command: The "Verb" (What to do)[cite: 74].
    • [cite_start]Short/Long Options: The "Switches" (Settings like sorting or long-listing)[cite: 74, 75].
    • [cite_start]Argument: The "Object" (What to act upon, e.g., a folder or file)[cite: 77].

    4. The "Holy Trinity" of Navigation

    [cite_start]Master these three to never get lost in your data[cite: 115].

    1. pwd: "Where am I?" (Print Working Directory) [cite_start][cite: 116].
    2. ls: "What is here?" (List files) [cite_start][cite: 118].
    3. [cite_start]cd: "Take me there" (Change Directory)[cite: 119].

    5. Biology File Operations

    [cite_start]Managing large-scale genomic datasets safely[cite: 135].

    Action Command Biology Example
    Creation mkdir / touch [cite_start]mkdir sequencing_reads[cite: 138].
    Organization cp / mv [cite_start]cp sample_R1.fq backup/[cite: 139].
    Inspection head / tail [cite_start]head -n 20 reads.fastq[cite: 185].
    Search grep [cite_start]grep 'GeneID:12345' records.txt[cite: 194].

    ⚠️ Danger Zone: Deleting is permanent. [cite_start]There is no 'Recycle Bin' in the CLI[cite: 148].
